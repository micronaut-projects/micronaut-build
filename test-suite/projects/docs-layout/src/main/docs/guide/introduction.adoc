The docs layout test-suite uses a small Micronaut-style project to exercise generated documentation.
It includes a nested table of contents, source snippets, configuration samples, dependencies, API links,
tables, notes, tips, and links to the https://docs.micronaut.io/latest/guide/[Micronaut user guide].

TIP: The same sample is used by the `test-suite` Gradle task so generated output is validated by JUnit.

NOTE: Source snippets live in the `test-suite` project and are consumed by the docs sample.

WARNING: Warning blocks use the same generated docs layout as notes.

IMPORTANT: Important blocks appear in Micronaut core docs and must keep platform styling.

class PointerExample { // <1>

        return "docs"; // <3>
    }
}
----
<1> Declares the example type used by the docs fixture.
<2> Marks the method that is referenced by the explanation.
<3> Returns the sample value shown in the code block.
